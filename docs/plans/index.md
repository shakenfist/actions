# Plans

Master plans for work in this repository. Each plan file holds its own
Execution table with per-phase status; the `Status` cell here is the
whole plan's. The vocabulary is the shared one from
shakenfist/development's `plan-status-vocabulary` block: `Proposed`,
`Not started`, `In progress`, `Blocked`, `Complete`, `Abandoned` or
`Superseded`.
